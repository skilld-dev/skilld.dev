# Keeping a reading list that works for you

A reading list helps you stay informed, but only if you can keep up with it. With some care, a collection of links can become a resource you actually learn from.

## A simple setup

Margin, our fictional reading-list app, keeps things simple. It stores a title, URL, and category for each link. You can filter by category and bookmark items you want to come back to. Everything stays in your browser, so there is no account or cloud sync.

## Building better habits

A weekly review helps you keep the collection under control. Remove links you no longer want to read. Keep the ones that connect to a project you are working on. That habit pays off over time.

The goal is a reading list that makes good use of your time. A small, focused list can be more useful than an extensive collection you never open.

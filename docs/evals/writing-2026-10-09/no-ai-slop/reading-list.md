# Keeping a reading list that works for you

A reading list doesn't need to be complicated. Margin, our fictional reading-list app, keeps yours simple, and a weekly review keeps it useful.

## A simple approach

Margin stores a title, URL, and category for each link. You can filter by category and bookmark items you want to return to. Everything stays in your browser. There's no account or cloud sync.

## Building better habits

Review the list once a week. Remove links you no longer want to read. Keep the ones that connect to a project you're working on. A small, focused list can be more useful than an extensive collection you never open.

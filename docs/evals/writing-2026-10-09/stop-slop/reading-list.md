# Keeping a reading list that works for you

Managing a reading list is part of staying informed. With a bit of care, you can turn a pile of links into a resource you learn from.

## A simple setup

A reading list doesn't need to be complicated. Our fictional reading-list app, Margin, keeps it simple. Margin stores a title, URL, and category for each link. You can filter by category and bookmark items you want to return to. Everything stays in your browser. There is no account and no cloud sync.

## Building better habits

A weekly review helps you manage a growing list of articles. Remove links you no longer want to read. Keep the ones tied to a project you're working on.

Aim for a reading rhythm that fits your time. A short, focused list serves you better than a long one you never open.

The nightly operator email for 2026-09-02 went AMBER on exactly this, with the single reason `Scheduled tasks partially failed: send-digests.`, sent at 2026-09-01T22:00:31Z on worker version `805ccae2`.

Hypothesis: this is an account-level billing condition on AI Gateway, not a code fault. Error `2021` is a credit exhaustion code, so every AI Gateway consumer is affected, not only the digest. Impact: Loop 2 retention. The monthly digest is the retention artefact, and it shipped without its summary for 100% of recipients.

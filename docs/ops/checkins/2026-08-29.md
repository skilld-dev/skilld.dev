## Broken

- Sentry [SKILLD-11](https://harlan-zw.sentry.io/issues/7676028614/) grew 41 to
  191 events and was still live at probe time, culprit
  `GET /api/skills-raw/theprimeagen/skills/better-auth-social-login`. The error
  shape changed to `Skill source is unavailable upstream`, the 503 that #94
  introduced for tree outages.
- Investigated read-only from production. Every tested skill in a non-`main`
  repository 503s: `theprimeagen/skills`, `fastapi/fastapi`,
  `vinta/awesome-python`, `vercel/next.js`, `n8n-io/n8n`. Every `main`
  repository 200s. Upstream serves each affected SKILL.md fine.
- Root cause: ungh nests `defaultBranch` under `.repo`. The handler asserted
  the type at the top level, so the read was always undefined and the branch
  fell back to `main`. `files/main` 404s for these repos, and #94 correctly
  turned that into a 503. `main` repos worked by coincidence.
- `repos.default_branch` already holds the right branch, and `skill-files`
  and `skill-asset` already read it there. `skills-raw` now does the same and
  drops the per-request ungh repo metadata call. Fix in
  [#96](https://github.com/skilld-dev/skilld.dev/pull/96), failing test first.

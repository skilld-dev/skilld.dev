### Three digest deliveries failed with `missing_recipient`

Evidence: `digest_runs` rows 44, 45, and one more at `window_end = 1785142800`, all `error_code = missing_recipient`, message `Digest user has no deliverable email address`. Users 17 (`clooz`), 19 (`qy1147680691`), and 30 (`hanswand`) each have `email_opt_in = 1`, `digest_frequency = weekly`, `onboarded_at` set, and both `email` and `digest_email` null.

Hypothesis, confirmed: `EmailPatchInput` accepted an optional unvalidated `digest_email`, so submitting the onboarding form with the opt-in box ticked and the address blank stored `digest_email = NULL` alongside `email_opt_in = 1`. `loadDigestEligibleUsers` then selects those users every cycle, `runDigestDeliveryForUser` claims a window, and preflight fails. Because these users are weekly, this reproduces once per week per user and holds the daily health report at RED on a condition no operator action can clear.
